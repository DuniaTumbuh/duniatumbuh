# DT-INV-RAG-001 — Knowledge Retrieval Proposal
Version: 0.1 | Status: OPTIONAL / REVIEW REQUIRED

Use approved, versioned documents for creator/operator guidance and cited character-identity QC. Start with Markdown and keyword search; evaluate RAG retrieval only after corpus and accuracy justify it. RAG must not act as event database, RSVP store, permission system, or authoritative transaction processor. Never index customer personal data or confidential assets in public search indexes. All responses must identify source version and evidence.
