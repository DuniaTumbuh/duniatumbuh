# Gate 2G — Mock-data Invitation Editor (non-production)
Standalone static HTML/CSS/JS. Open index.html in a browser or serve this folder with any local static server. No install, external dependencies, network API, localStorage, cookies, real QR, RSVP, database, payments, microphone, camera, AI calls or production deployment.

## Manual checks (NOT RUN)
1. Choose evt-a, edit title, preview, publish; switch evt-b and evt-c and verify unchanged.
2. Publish evt-a twice, rollback and verify earlier snapshot restored; note this is local in-memory simulation, NOT atomic server publishing.
3. Configure cake/candles, press blow button, check reduced-motion and narrow screen.
4. Turn mute off then play synthesized sine-tone audio; stop/mute; browser may block audio. This is NOT a licensed birthday track or canonical Dino voice.
5. Reload page and verify fixtures reset (intentional).
6. Confirm no RSVP or real event URLs; QR, auth, isolation security, API, backend, live event retention and version compatibility are NOT implemented or tested.

## Known limitations
Prototype UI demonstrates isolated event configuration only. It does NOT establish secure tenant separation, stable QR, backend persistence, transaction safety, accessibility conformance, canonical character art, commercial audio licensing or release readiness. Emoji art is placeholder. The audio is a single demo tone, not birthday music. Do not publish for children or use with customer data.
