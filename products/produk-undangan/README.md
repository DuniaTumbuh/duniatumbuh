# Produk Undangan — Dunia Tumbuh

Status: GATE 1 / DOCUMENTATION CANDIDATE / REVIEW REQUIRED.

Produk Undangan adalah lini produk Dunia Tumbuh berbasis satu platform multi-universe. Pilot pertama adalah **Dino Adventure**. Universe terpisah **Nimo & Friends** (Nimo, Lumi, Tuki, Momo) disiapkan untuk ekspansi; identitas dan aset IP tidak boleh dicampur.

Bentuk produk: (1) Pop-Up fisik + QR WebAR, (2) kartu fisik/digital Motion Graphics 3D/AR, (3) panggung fisik Pepper's Ghost berbasis satu PET dan HP tersembunyi.

Prinsip: Play First • Learn Naturally • Parents as Partners; konfigurasi per acara tanpa deploy; preview/review/publish; akses informasi pesta tidak boleh bergantung pada game; no merge/no production deployment pada Gate 1.
