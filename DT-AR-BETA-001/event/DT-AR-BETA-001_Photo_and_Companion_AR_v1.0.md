# DT-AR-BETA-001 — Photo and Companion AR v1.0

**Status:** CANONICAL — FOUNDER APPROVED

## PHOTO-01
**P1 HIGH VALUE.** Preferred format: approximately four groups of five students, or post-session 3–5 minute optional photo period if core timing is tight.

## Teacher/Parent Companion
QR → browser → camera → Nimo → local reposition → local “Foto dengan Nimo”.

Safety architecture: no facial recognition; no autonomous child identification; no automatic cloud upload; no persistent child-image storage by default; no Wizard/event-control authority; user/device retains local photo unless an explicitly authorized workflow says otherwise.

Implementation remains PROVISIONAL pending compatibility testing.
