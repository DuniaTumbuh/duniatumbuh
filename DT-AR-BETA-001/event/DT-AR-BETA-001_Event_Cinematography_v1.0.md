# DT-AR-BETA-001 — Event Cinematography v1.0

**Status:** CANONICAL — FOUNDER APPROVED

## Coverage Architecture
- **CAM-A — MASTER:** continuous wide/safety recording.
- **CAM-B — CINEMATIC:** Fuji X-S10 or equivalent for reaction, movement and detail.
- **FEED-C — DIGITAL:** clean laptop/projector/AR output.
- **CAM-D — MOBILE POV:** selected Vivo/teacher/parent device perspective where feasible.

## Shot Language
Wide establishing; slow push-in; controlled pull-out; reaction close-up; over-the-shoulder; child-level POV; controlled orbit/180–360° movement; device POV; selective slow motion; group/Nimo shot; safe overhead shot only if the location provides a safe elevated camera position.

No operator may stand unsafely on furniture or improvise an overhead rig above children.

Capture several seconds before the reveal. Preserve authentic normal → curious → realization → surprise → joy. Do not ask children to recreate first reactions.
